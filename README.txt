BARAKA MB — PERSONAL WEBSITE
================================

Files:
- index.html: website content
- style.css: responsive professional design
- script.js: Swahili/English language switch and mobile navigation
- assets/baraka-mb-portrait.png: profile portrait

DEPLOY TO NETLIFY:
1. Extract this ZIP on your phone or computer.
2. Open https://app.netlify.com/drop in your browser.
3. Upload the extracted website folder (or drag the ZIP if Netlify accepts it).
4. Netlify will publish a temporary site address.
5. To use barakamb.netlify.app, open Site configuration / Domain management and change the site name to barakamb, if that name is available.

Before publishing, review all biography details and public contact information.
Facebook and TikTok are displayed as names only because direct profile URLs were not supplied.
